# `modulos` — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** uma terceira ferramenta no servidor `usp-jupiter`, `modulos(busca, disciplina)`, que responde "quais módulos da Poli existem e qual tem menor carga", "que disciplinas tem o módulo X" e "em que módulo está a disciplina Y" — com busca em linguagem natural feita no servidor e resposta de dezenas a ~1.500 tokens.

**Architecture:** o servidor monta, na primeira chamada, um índice dos 50 módulos/percursos da Poli (2 páginas HTML `jupCursoLista` + 100 chamadas DWR, ~22 s) e o guarda em memória por 7 dias. A busca, o cruzamento e a formatação rodam em Python sobre o índice; o cru da USP (~104 mil tokens) nunca chega ao modelo. Dois módulos novos: `usp_mcp/jupiter/indice.py` (ler a lista, montar o índice, cache) e `usp_mcp/jupiter/modulos.py` (normalizar, buscar, responder em texto).

**Tech Stack:** Python 3, stdlib (`re`, `html`, `unicodedata`, `threading`), SDK `mcp` só em `server.main()`, pytest. Sem dependência nova.

**Spec:** `docs/superpowers/specs/2026-10-26-modulos-design.md`. Leia antes de começar.

```python
import json
import re
from urllib.parse import unquote

MODULOS = {
    "lista_N": "html-jupCursoLista-codcg3-N.html",
    "lista_V": "html-jupCursoLista-codcg3-V.html",
    "respostas": "dwr-modulos-poli.json",
}


@pytest.fixture
def lista_n():
    return (FIXTURES / MODULOS["lista_N"]).read_bytes()


@pytest.fixture
def lista_v():
    return (FIXTURES / MODULOS["lista_V"]).read_bytes()


@pytest.fixture
def respostas_modulos():

class RoteadorDWR:
    """Transporte DWR falso que responde pela CONSULTA e pelos PARÂMETROS que
    saíram no corpo — não pela ordem das chamadas.

    É o que permite asserir o parâmetro ENVIADO (regra 11 do CLAUDE.md): a
    chave `consulta|codcur|codhab|tipo` só existe na fixture se o `tipo` que
    saiu for o certo, e uma chave sem resposta derruba o teste em vez de
    devolver qualquer coisa.
    """

    def __init__(self, respostas):
        self.respostas = dict(respostas)
        self.enviados = []

    def __call__(self, url, corpo, cabecalhos):
        campos = dict(l.split("=", 1) for l in corpo.splitlines() if "=" in l)
        consulta = campos["c0-param0"].split(":", 1)[1]
        refs = sorted((k for k in campos if re.fullmatch(r"c0-e\d+", k)), key=lambda k: int(k[4:]))
        valores = [unquote(campos[k].split(":", 1)[1]) for k in refs]
        chave = "|".join([consulta, *valores])
        self.enviados.append(chave)
        if chave not in self.respostas:
            raise AssertionError(f"chamada sem fixture: {chave}")
        return 200, self.respostas[chave]


class GetPorTipo:
    """Transporte GET falso das duas listas de curso, escolhidas pelo `tipo=`
    da URL pedida."""

    def __init__(self, lista_n, lista_v, status=200):
        self._por_tipo = {"N": lista_n, "V": lista_v}
        self.status = status
        self.urls = []

    def __call__(self, url, cabecalhos):
        self.urls.append(url)
        tipo = re.search(r"[?&]tipo=([A-Z])", url).group(1)
        return self.status, self._por_tipo[tipo]
```

```python
"""O índice dos módulos da Poli: a lista de cursos e os envelopes, uma vez só.

As três perguntas da ferramenta `modulos` são sobre TODOS os módulos — "qual
tem menor carga", "onde está esta disciplina" —, e o dado para isso são 2
páginas e 100 chamadas DWR (~22 s, medido em 27/10). Feito por pergunta, isso
seria a ferramenta chamada "mais vezes do que deveria". Feito uma vez, o
índice guarda só o que a resposta usa: 6 campos de cada disciplina e 6 de
carga, contra os 17 de cada registro cru (~104 mil tokens no total).

**O `tipo` é o do link ATIVO da lista.** Cada linha traz o link duas vezes —
um comentado em `<!-- -->`, com o `tipo` antigo, e o que a página usa. Os
comentários saem antes de qualquer leitura: o comentado diz `N` para os
percursos e o ativo diz `V`, e foi um `tipo` errado que fez a medição de 14/09
concluir que módulo não tinha grade.

**Módulo é reconhecido pela seção ou pelo prefixo, nunca por palavra do nome.**
"Trilha Formativa" virou "Percurso Formativo" entre duas medições (22 e 27/10).
A seção "Módulo" da tabela e o prefixo "Módulo:" são estrutura; o nome é texto.
"""
from __future__ import annotations

import html
import re
import threading
import time
from dataclasses import dataclass
from typing import Callable

from .erros import JupiterErro, JupiterIndisponivel, RespostaInvalida

__all__ = ["Linha", "Disciplina", "Modulo", "Indice", "ler_lista", "cursos_base",
           "montar_indice", "CacheDoIndice", "TTL_INDICE"]

# Uma semana. Módulo muda por revisão de currículo, não por semana; mas a grade
# do currículo novo cresceu de 67 para 89 registros entre 14/09 e 22/10, e um
# índice sem validade num servidor que fica de pé por semanas mentiria calado.
TTL_INDICE = 7 * 24 * 3600

_COMENTARIO = re.compile(r"<!--.*?-->", re.S)
_LINHA = re.compile(r"<tr\b.*?</tr>", re.S | re.I)
_CELULA = re.compile(r"<td\b[^>]*>(.*?)</td>", re.S | re.I)
_LINK = re.compile(
    r"listarGradeCurricular\?codcg=\d+&(?:amp;)?codcur=(\d+)&(?:amp;)?codhab=(\d+)"
    r"&(?:amp;)?tipo=([A-Z])"
)
_TAG = re.compile(r"<[^>]+>")
_PREFIXO_DO_NOME = re.compile(r"^(?:Engenharia - )?(?:Módulo:\s*)?")


@dataclass(frozen=True)
class Linha:
    codcur: str
    codhab: str
    tipo: str
    nome: str
    modulo: bool


@dataclass(frozen=True)
class Disciplina:
    sigla: str
    nome: str
    creditos_aula: int
    creditos_trabalho: int
    semestre: int | None
    tipo: str  # O obrigatória, C optativa eletiva, L optativa livre


@dataclass(frozen=True)
class Modulo:
    codcur: str
    codhab: str
    tipo: str
    nome: str
    curso: str
    carga_total: int | None
    carga_obrigatoria: int | None
    carga_eletiva: int | None
    carga_livre: int | None
    disciplinas: tuple[Disciplina, ...]
    falhou: bool = False

    @property
    def codigo(self) -> str:
        return f"{self.codcur}/{self.codhab}"

    @property
    def nome_curto(self) -> str:
        """Sem "Módulo:" nem "Engenharia - ": estão em todo nome e não dizem nada.
        "Percurso Formativo:" fica — é o que distingue o percurso do módulo."""
        return _PREFIXO_DO_NOME.sub("", self.nome)

    @property
    def situacao(self) -> str:
        if self.falhou:
            return "falhou"
        if not self.disciplinas and self.carga_total is None:
            return "nao_publicado"
        if not self.disciplinas:
            return "sem_grade"
        return "ok"


@dataclass(frozen=True)
class Indice:
    modulos: tuple[Modulo, ...]


def _texto(trecho: str) -> str:
    return re.sub(r"\s+", " ", html.unescape(_TAG.sub(" ", trecho))).strip()


def ler_lista(bruto: bytes) -> list[Linha]:
    """Toda linha com link de grade, na ordem da página, marcada se é módulo.

    O nome é a penúltima célula nas duas listas: `N` tem [link, nome, período]
    e `V` tem [link, curso, nome, período].
    """
    pagina = _COMENTARIO.sub("", bruto.decode("iso-8859-1"))
    linhas: list[Linha] = []
    secao = ""
    for tr in _LINHA.finditer(pagina):
        bloco = tr.group(0)
        link = _LINK.search(bloco)
        if link is None:
            cabecalho = _texto(bloco)
            if cabecalho.startswith("Módulo"):
                secao = "modulo"
            elif cabecalho.startswith("Curso"):
                secao = "curso"
            continue
        celulas = [_texto(c) for c in _CELULA.findall(bloco)]
        if len(celulas) < 3:
            continue
        nome = celulas[-2]
        codcur, codhab, tipo = link.groups()
        linhas.append(Linha(codcur, codhab, tipo, nome,
                            modulo=secao == "modulo" or nome.startswith("Módulo:")))
    return linhas


def cursos_base(linhas: list[Linha]) -> dict[str, str]:
    """O nome do curso de cada `codcur`: a linha não-módulo de `codhab` 0, ou a
    de menor `codhab`. É o que deixa "elétrica" achar os módulos do 3032, cujo
    nome não diz o curso."""
    base: dict[str, str] = {}
    candidatas = sorted((l for l in linhas if not l.modulo),
                        key=lambda l: (l.codhab != "0", int(l.codhab)))
    for linha in candidatas:
        base.setdefault(linha.codcur, linha.nome)
    return base


def _inteiro(valor) -> int | None:
    if valor in (None, ""):
        return None
    return int(valor)


def _soma(ficha: dict, *campos: str) -> int | None:
    valores = [_inteiro(ficha.get(c)) for c in campos]
    if all(v is None for v in valores):
        return None
    return sum(v or 0 for v in valores)


def _disciplina(registro: dict) -> Disciplina:
    return Disciplina(
        sigla=registro["coddis"],
        nome=registro["nomdis"],
        creditos_aula=_inteiro(registro.get("creaul")) or 0,
        creditos_trabalho=_inteiro(registro.get("cretrb")) or 0,
        semestre=_inteiro(registro.get("numsemidl")),
        tipo=registro.get("tipobg") or "?",

def _ler_modulo(cliente, linha: Linha, curso: str) -> Modulo:
    # Só falha de TRANSPORTE ou de RESPOSTA é isolada. `ConsultaNegada` sobe:
    # política negando uma consulta da própria fatia é defeito de código, e
    # escondê-la num "não pôde ser lido" seria o silêncio do Invariante 6.

        ficha = cliente.info_curriculo(linha.codcur, linha.codhab, linha.tipo)
        grade = cliente.grade_curricular(linha.codcur, linha.codhab, linha.tipo)
    except (JupiterIndisponivel, RespostaInvalida, JupiterErro):
        return Modulo(linha.codcur, linha.codhab, linha.tipo, linha.nome, curso,
                      None, None, None, None, (), falhou=True)
    return Modulo(
        codcur=linha.codcur,
        codhab=linha.codhab,
        tipo=linha.tipo,
        nome=linha.nome,
        curso=curso,

        carga_obrigatoria=_soma(ficha, "cgahorobgaul", "cgahorobgtrb"),
        carga_eletiva=_soma(ficha, "cgaoptcplaul", "cgaoptcpltrb"),
        carga_livre=_soma(ficha, "cgaoptlreaul", "cgaoptlretrb"),

def montar_indice(cliente) -> Indice:
    """As duas listas, e ficha + grade de cada módulo, uma requisição por vez
    (a porta do cliente já serializa: Invariante 5)."""
    linhas = (ler_lista(cliente.obter_lista_cursos_poli("N"))
              + ler_lista(cliente.obter_lista_cursos_poli("V")))
    base = cursos_base(linhas)
    vistos: set[tuple[str, str]] = set()
    modulos: list[Modulo] = []
    for linha in linhas:
        par = (linha.codcur, linha.codhab)
        if not linha.modulo or par in vistos:
            continue
        vistos.add(par)
        modulos.append(_ler_modulo(cliente, linha, base.get(linha.codcur, "")))
    if not modulos:
        raise RespostaInvalida(
            "as listas de cursos da Poli vieram sem nenhum módulo. Elas tinham a "
            "forma certa, então a tabela mudou de layout ou a seção sumiu. NÃO "
            "leia isto como 'a Poli não tem módulo' — em 26/10 eram 50."
        )
    return Indice(tuple(modulos))


class CacheDoIndice:
    """O índice de um processo, por `TTL_INDICE`. Um só, e montado uma vez por
    vez: duas perguntas simultâneas não podem fazer 200 chamadas à USP."""

    def __init__(self, *, relogio=time.monotonic, ttl: int = TTL_INDICE):
        self._relogio = relogio
        self._ttl = ttl
        self._guardado: tuple[float, Indice] | None = None
        self._porta = threading.Lock()

    def obter(self, construir: Callable[[], Indice]) -> Indice:
        with self._porta:
            if self._guardado and self._relogio() - self._guardado[0] < self._ttl:
                return self._guardado[1]
            indice = construir()
            # Índice com módulo falho NÃO fica: a próxima pergunta tenta de novo,
            # em vez de responder sem aquele módulo por uma semana.
            if not any(m.falhou for m in indice.modulos):
                self._guardado = (self._relogio(), indice)
            return indice
```

```python
"""A ferramenta `modulos`: busca em linguagem natural e o texto da resposta.

**A busca roda aqui, não no modelo.** Ninguém pergunta por "3032/5080"; pergunta
por "o módulo de sistemas eletrônicos". Casar isso no servidor custa zero token,
e a regra que segura o custo é uma só: **em dúvida, candidato; grade só quando
a busca resolve para um módulo.** Uma ambiguidade nunca vira 50 grades.

**O casamento é o mínimo que passou na medição de 26/10:** sem acento e sem
caixa, sem palavra vazia, e toda palavra da busca é prefixo de alguma do alvo,
com folga de 2 letras para palavras de 6+ ("telecom" acha "telecomunicações",
"eletrônicos" acha "eletrônica"). Erro de digitação no meio da palavra não é
tratado de propósito: o modelo corrige digitação melhor, e de graça.

**Ressalva só quando o dado a produz** (Achado 1 de `notas/custo-em-token.md`):
o que vale sempre — só a Poli tem módulo, elegibilidade não sai daqui, o que é
O/C/L — está na descrição, que se paga uma vez por sessão.
"""
from __future__ import annotations

import re
import unicodedata

from .indice import Indice, Modulo

__all__ = ["normalizar", "casa", "e_sigla", "filtrar", "responder"]

# Artigos e preposições, mais as palavras que estão em todo nome e não
# discriminam nada: "engenharia" está em todos os 50.
_VAZIAS = frozenset({
    "a", "o", "as", "os", "de", "do", "da", "dos", "das", "e", "em", "no", "na",
    "para", "com", "modulo", "modulos", "materia", "materias", "disciplina",
    "disciplinas", "engenharia",
})
_SIGLA = re.compile(r"^[A-Z0-9]{5,8}$")
_TRES_DIGITOS = re.compile(r"\d{3}")
_CODIGO = re.compile(r"^\s*(\d{4,5})\s*[/ ]\s*(\d{1,4})\s*$")

# Invariante 7: quando corta, diz quanto cortou.
TETO_CANDIDATOS = 20
TETO_DISCIPLINAS = 25


def normalizar(texto: str) -> str:
    sem_acento = "".join(
        c for c in unicodedata.normalize("NFKD", texto) if not unicodedata.combining(c)
    )
    return re.sub(r"[^a-z0-9]+", " ", sem_acento.lower()).strip()


def _palavras(texto: str) -> list[str]:
    return [p for p in normalizar(texto).split() if len(p) > 1 and p not in _VAZIAS]


def _raiz(palavra: str) -> str:
    return palavra[:-2] if len(palavra) >= 6 else palavra


def casa(busca: str, alvo: str) -> bool:
    pedidas = _palavras(busca)
    if not pedidas:
        return False
    do_alvo = normalizar(alvo).split()
    return all(any(a.startswith(_raiz(p)) for a in do_alvo) for p in pedidas)


def e_sigla(texto: str) -> bool:
    compacto = "".join(texto.split()).upper()
    return bool(_SIGLA.match(compacto) and _TRES_DIGITOS.search(compacto))


def _so_vazias(busca: str) -> bool:
    return not _palavras(busca) and not _CODIGO.match(busca)


def filtrar(modulos, busca: str) -> list[Modulo]:
    codigo = _CODIGO.match(busca)
    if codigo:
        alvo = f"{codigo.group(1)}/{codigo.group(2)}"
        return [m for m in modulos if m.codigo == alvo]
    return [m for m in modulos if casa(busca, f"{m.nome} {m.curso}")]


# --- pedaços de texto --------------------------------------------------------

def _carga(m: Modulo) -> str:
    return f"{m.carga_total} h" if m.carga_total is not None else "carga não publicada"


def _divisao(m: Modulo) -> str:
    partes = [f"{rotulo} {valor}" for rotulo, valor in (
        ("obrigatória", m.carga_obrigatoria), ("eletiva", m.carga_eletiva),
        ("livre", m.carga_livre)) if valor]
    return " · ".join(partes)


def _semestre(s: int | None) -> str:
    return f"{s}º semestre ideal" if s is not None else "sem semestre ideal"


def _ressalvas(modulos) -> list[str]:
    por: dict[str, list[str]] = {}
    for m in modulos:
        por.setdefault(m.situacao, []).append(m.codigo)
    linhas = []
    if por.get("sem_grade"):
        n = len(por["sem_grade"])
        linhas.append(f"⚠ {n} com a grade vazia no Jupiter — só a carga foi publicada: "
                      f"{', '.join(por['sem_grade'])}.")
    if por.get("nao_publicado"):
        n = len(por["nao_publicado"])
        linhas.append(f"⚠ {n} sem grade nem carga publicadas no Jupiter: "
                      f"{', '.join(por['nao_publicado'])}.")
    if por.get("falhou"):
        n = len(por["falhou"])
        linhas.append(f"⚠ {n} não puderam ser lidos agora (o JupiterWeb falhou nesta "
                      f"consulta) e ficaram de fora: {', '.join(por['falhou'])}.")
    return linhas


# --- as cinco formas de resposta --------------------------------------------

def _ranking(indice: Indice) -> str:
    ms = indice.modulos
    linhas = [f"{len(ms)} módulos e percursos da Poli, por curso. Carga = horas que o "
              "currículo do módulo exige."]
    com_carga = [m for m in ms if m.carga_total is not None]
    if com_carga:
        menor = min(m.carga_total for m in com_carga)
        empatados = [m for m in com_carga if m.carga_total == menor]
        linhas.append("Menor carga: " + "; ".join(
            f"{menor} h — {m.nome_curto} ({m.codigo})" for m in empatados) + ".")
    grupos: dict[str, list[Modulo]] = {}
    for m in ms:
        grupos.setdefault(m.codcur, []).append(m)
    for codcur in sorted(grupos, key=lambda c: (grupos[c][0].curso or c, c)):
        membros = sorted(grupos[codcur], key=lambda m: (
            m.carga_total is None, m.carga_total or 0, m.nome_curto))
        linhas.append("")
        linhas.append(f"{membros[0].curso or 'Curso'} ({codcur})")
        for m in membros:
            divisao = _divisao(m)
            detalhe = f" ({divisao})" if divisao else ""
            n = len(m.disciplinas)
            linhas.append(f"  {_carga(m)}{detalhe}  {m.nome_curto} — {m.codigo}, "
                          f"{n} disc.")
    ressalvas = _ressalvas(ms)
    if ressalvas:
        linhas.append("")
        linhas.extend(ressalvas)
    return "\n".join(linhas)


def _um(m: Modulo) -> str:
    linhas = [f"{m.nome_curto} — {m.codigo} · curso: {m.curso or m.codcur}"]
    divisao = _divisao(m)
    carga = f"Carga exigida: {_carga(m)}" + (f" ({divisao})" if divisao else "")
    linhas.append(f"{carga}. {len(m.disciplinas)} disciplinas.")
    por_semestre: dict[int | None, list] = {}
    for d in m.disciplinas:
        por_semestre.setdefault(d.semestre, []).append(d)
    for s in sorted(por_semestre, key=lambda s: (s is None, s or 0)):
        linhas.append("")
        linhas.append(_semestre(s))
        for d in sorted(por_semestre[s], key=lambda d: (d.tipo, d.sigla)):
            linhas.append(f"  {d.tipo} {d.sigla} {d.nome} "
                          f"({d.creditos_aula}+{d.creditos_trabalho})")
    ressalvas = _ressalvas([m])
    if ressalvas:
        linhas.append("")
        linhas.extend(ressalvas)
    return "\n".join(linhas)


def _candidatos(busca: str, escolhidos: list[Modulo]) -> str:
    linhas = [f'"{busca}" casou com {len(escolhidos)} módulos. Peça um pelo código '
              "para ver as disciplinas:"]
    for m in sorted(escolhidos, key=lambda m: m.codigo)[:TETO_CANDIDATOS]:
        linhas.append(f"  {m.codigo} {m.nome_curto} — {_carga(m)} — {m.curso or m.codcur}")
    if len(escolhidos) > TETO_CANDIDATOS:
        linhas.append(f"  … e mais {len(escolhidos) - TETO_CANDIDATOS}. Refine a busca.")
    return "\n".join(linhas)


def _nenhum(busca: str, indice: Indice) -> str:
    cursos = sorted({(m.codcur, m.curso) for m in indice.modulos})
    linhas = [f'Nenhum módulo casou com "{busca}". Os cursos da Poli que têm módulo:']
    linhas.extend(f"  {codcur} {curso}".rstrip() for codcur, curso in cursos)
    linhas.append("Busque pelo nome do módulo, pelo curso ou pelo código (3032/5080).")
    return "\n".join(linhas)


def _por_disciplina(pedida: str, escopo: list[Modulo]) -> str:
    alcancados = [m for m in escopo if m.disciplinas]
    if e_sigla(pedida):
        sigla = "".join(pedida.split()).upper()
        achados = [(m, d) for m in alcancados for d in m.disciplinas if d.sigla == sigla]
        if achados:
            n = len({m.codigo for m, _ in achados})
            linhas = [f"{sigla} {achados[0][1].nome} — em {n} "
                      f"{'módulo' if n == 1 else 'módulos'}:"]
            linhas.extend(f"  {m.codigo} {m.nome_curto} ({d.tipo}, {_semestre(d.semestre)})"
                          for m, d in achados)
        else:
            parecidas = sorted({(d.sigla, d.nome) for m in alcancados for d in m.disciplinas
                                if d.sigla[-4:] == sigla[-4:] and d.sigla[:2] == sigla[:2]})
            linhas = [f"{sigla} não aparece em nenhum módulo da Poli."]
            if parecidas:
                linhas[0] += " Siglas parecidas que aparecem:"
                linhas.extend(f"  {s} {nome}" for s, nome in parecidas)
            else:
                linhas[0] += " Nenhuma sigla parecida aparece nos módulos."
    else:
        grupos: dict[str, tuple[str, list[Modulo]]] = {}
        for m in alcancados:
            for d in m.disciplinas:
                if casa(pedida, d.nome):
                    grupos.setdefault(d.sigla, (d.nome, []))[1].append(m)
        if not grupos:
            linhas = [f'Nenhuma disciplina dos módulos casou com "{pedida}".']
        else:
            linhas = [f'"{pedida}" casou com {len(grupos)} disciplinas dos módulos:']
            for sigla in sorted(grupos)[:TETO_DISCIPLINAS]:
                nome, ms = grupos[sigla]
                onde = ", ".join(f"{m.nome_curto} ({m.codigo})" for m in ms)
                linhas.append(f"  {sigla} {nome} — {onde}")
            if len(grupos) > TETO_DISCIPLINAS:
                linhas.append(f"  … e mais {len(grupos) - TETO_DISCIPLINAS}. Refine a busca.")
    fora = _ressalvas([m for m in escopo if m.situacao != "ok"])
    if fora:
        linhas.append("")
        linhas.append("A busca não alcança os módulos sem grade:")
        linhas.extend(fora)
    return "\n".join(linhas)


def responder(indice: Indice, *, busca: str = "", disciplina: str = "") -> str:
    escopo = list(indice.modulos)
    if busca.strip() and not _so_vazias(busca):
        escolhidos = filtrar(escopo, busca)
        if not escolhidos:
            return _nenhum(busca, indice)
        if not disciplina.strip():
            if len(escolhidos) == 1:
                return _um(escolhidos[0])
            return _candidatos(busca, escolhidos)
        escopo = escolhidos
    if disciplina.strip():
        return _por_disciplina(disciplina, escopo)
    return _ranking(indice)
```
